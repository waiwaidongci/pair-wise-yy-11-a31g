# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

给潜水店使用的气瓶充填前端系统，在原有充填记录基础上扩展为「阀颈扭矩复核 + 充填后泄漏放行台」。

## 业务规则

- **入队登记**：气瓶编号、容积、检验有效期、残压、目标压力、氧/氦含量、充填方式、操作员；同瓶仅允许一条未结束单据。
- **阀颈装配复核**：每瓶仅一张未结束装配复核单，重复或并发打开沿用首次单号；登记阀体号、O 型圈批次、扭矩（35~45 N·m）、装配人。扭矩越界或 O 型圈批次过期/不在台账，只进「待检」，不得充填；更正后在同一张单上重审。
- **充填静置**：复核通过后才能充填，充填后静置 5 分钟。
- **泄漏放行签收**：泄漏压降 > 3 bar 不得签收；复核人不得与装配人为同一人；签收时冻结装配快照。
- **返工失效**：换阀或更正扭矩发生在充填/签收之后，静置作废；已签收的原放行立即失效，须重新充填、静置、签收，并在单瓶履历留痕。
- **存档**：localStorage 持久化，队列与单瓶履历刷新后一致；多标签页通过 storage 事件同步。

## 文件结构（规则 / 存档 / 界面三分）

- `src/business/rules.ts` — 规则常量、类型与纯函数判定（扭矩、批次、静置、泄漏、职责分离、混合气、检验期）
- `src/business/archive.ts` — 存档层：唯一未结复核单、装配留痕、放行失效、事件履历
- `src/business/Station.tsx` — 界面：登记表单、复核单、静置进度与签收、队列筛选、单瓶履历时间轴
