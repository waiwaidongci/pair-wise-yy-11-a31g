# hxyfront-62010 潜水气瓶阀颈复核与充填放行台

源提示词编号：5

给潜水店使用的气瓶充填前端工作台，在原有气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员记录上，增加阀颈扭矩复核、充填后静置泄漏复核、放行签收和单瓶履历。

## 业务规则

- 每瓶同一时间只保留一张未结束装配复核单；重复登记或多个标签页并发登记相同气瓶时，沿用首次创建的复核单。
- 登记阀体号、O 型圈批次及有效期、阀颈扭矩和装配人。
- 阀颈扭矩必须在 35–45 N·m；O 型圈批次过期或其他复核项不合格时，复核单只进入“待检”，不能充填。
- 充填完成后按真实完成时间静置五分钟；刷新或重开页面后倒计时继续。
- 五分钟泄漏压降超过 3 bar 时扣留返修；放行复核人与装配人相同时禁止签收。
- 换阀或更正扭矩会生成接替复核单，并把原有效放行标记为失效；队列、单瓶履历和刷新后的存档保持一致。
- 所有记录保存在浏览器 localStorage，并通过 `storage` 事件在多个标签页之间同步。

## 代码划分

- `src/rules.ts`：业务常量、类型、纯规则函数和队列状态推导。
- `src/archive.ts`：localStorage 存档、跨标签页同步、演示数据和所有履历变更命令。
- `src/App.tsx`：登记表单、放行队列、返修操作和单瓶履历界面。
